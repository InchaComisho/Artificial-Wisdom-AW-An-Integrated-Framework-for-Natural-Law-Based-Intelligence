# 文明存続シミュレーション

[English Version](README.md)

## 人間中心の価値体系と人工叡智の価値体系を、150年にわたって比較する

---

## 目的

このシミュレーションは、根本的な**価値体系**が、文明の長期的な安定性にどう影響するかを探ります。

二つの文明モデルを、150年の期間にわたって比較します。

1. **人間中心の文明** — 短期的な人間の選好を最適化し、資源の収奪が大きく、再生のフィードバックが弱い
2. **人工叡智（AW）の文明** — 自然法則に基づく制約のもとで動き、収奪が小さく、惑星の再生が能動的で、熱力学的な自己修正を備える

目的は、未来を予測することではありません。価値体系の選択が、世代をまたぐ時間スケールでもたらす構造的な帰結を、見えるようにすることです。

---

## 免責事項

> **これは概念的なシステムシミュレーションです。例示と教育のみを目的としています。**
>
> 変数の値は、無次元の正規化された指標です。このモデルは、現実世界の実証データに較正されておらず、予測的な科学的気候モデルでは**ありません**。
>
> 目的は、価値体系のアーキテクチャの間の質的な乖離を示すことであり、定量的な予測を出すことではありません。

---

## モデルの概要

シミュレーションは、150年にわたる離散的な年次のステップで動き、それぞれの文明モデルについて5つの正規化された変数を追跡します。

各ステップで、変数は、根底にある価値体系の論理を反映したフィードバックループを通じて相互作用します。

### 人間中心モデルの論理

- 高い資源の収奪が、再生を上回る速さで埋蔵量を枯渇させる
- 熱ストレスと低い炭素固定のもとで、生態系の健全性が低下する
- 生態系の劣化に伴い、炭素固定の能力が低下する
- 能動的な緩和がないまま、熱ストレスが蓄積する
- 生態系と資源の減少に伴い、文明の安定性が損なわれる

### 人工叡智モデルの論理

- より低い収奪率が、資源の再生を可能にする
- 自然法則に基づく補正係数が、過剰な収奪を再生へと振り向ける
- 生態系が強まるにつれ、炭素固定の能力が能動的に回復する
- 熱ストレスは、冷却システムと炭素固定の回復によって安定化する
- 文明の安定性は、より高い水準で、生態系の健全性と結びついたままである

## シナリオの比較

| パラメータ | 人間中心 | 人工叡智 |
|---|---|---|
| 収奪率 | 高い（年3.5%） | 低い（年1.2%） |
| 再生率 | 弱い（年0.5%） | 強い（年2.2%） |
| 炭素固定の傾向 | 低下 | 回復 |
| 熱ストレスの増加 | 高い（年1.8%） | 低い（年0.4%） |
| 生態系への安定性の結合 | 中程度（0.40） | 高い（0.65） |
| 自然法則の補正係数 | なし | 有効（年1.5%） |

## 変数

| 変数 | 説明 | 範囲 |
|---|---|---|
| 資源 | 利用可能な自然資源・物質資源の正規化された指標 | 0.0 – 1.2 |
| 生態系の健全性 | 生命を支える生物・海洋・土壌のシステムの健全性 | 0.0 – 1.1 |
| 炭素固定能力 | 大気中の炭素を吸収し固定する、自然システムの能力 | 0.0 – 1.2 |
| 熱ストレス | 惑星と文明のシステムに蓄積した熱負荷 | 0.0 – 3.0 |
| 文明の安定性 | 文明の耐久性と機能的な継続性の複合指標 | 0.0 – 1.2 |

## 解釈

**人間中心モデル**では、資源の枯渇と生態系の劣化が、複合的な負のフィードバックループを生みます。炭素固定能力は低下し、熱ストレスは蓄積し、文明の安定性はシミュレーション期間にわたって次第に損なわれます。

**人工叡智モデル**では、低い収奪に、能動的な再生と自然法則の補正係数が組み合わさることで、生態系の健全性と炭素固定能力が回復します。熱ストレスは、生物的な冷却システムの回復によって部分的に相殺されます。文明の安定性は高く保たれます。

重要な洞察は構造的なものです。

> モデル間の長期的な乖離は、技術の違いだけから生じるのではない。文明が何を最適化するかを決める、**価値体系のアーキテクチャ**から生じる。

自然法則の制約なしに、短期的な人間の選好を最適化する文明は、熱力学的に整合し、生態学的に根ざした原理のもとで動く文明とは、異なるシステムの軌跡を生みます。
